Privacy note

Last updated: 26 October 2026

Speaker Cleaner is a static website hosted on GitHub Pages. The cleaning tones are generated entirely inside your browser using the Web Audio API.

  • No account, sign-up, or personal information is required.
  • The site does not use your microphone and does not record or upload any audio.
  • The optional vibration feature uses your browser's Vibration API on your own device only.
  • The site sets no cookies and includes no analytics or advertising scripts.
  • Like any website, the hosting provider (GitHub) may process basic technical data such as IP addresses in server logs to deliver and secure the site. See GitHub's own privacy statement for details.

If this note changes, the date above will be updated. Questions can be raised on the contact page.
